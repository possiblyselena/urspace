What is Urspace?

Urspace is a You-Ship, We-Ship program run by Hack Club

  • 1. Make a project and Track using Hackatime!
  • 2. Submit project for review here
  • 3. Once finished, we ship you fairy lights!

Projects < 5 hours = random lights from hq (while supplies last)

Projects > 5 hours = cute ones from Amazon!!
